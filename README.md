# GAMES — مرکز بازی‌های مرورگری

یک Game Hub استاتیک و فارسی برای GitHub Pages؛ واکنش‌گرا برای موبایل، کامپیوتر و صفحه‌های بزرگ، با حالت کنسول و کنترل دسته از طریق Gamepad API.

## بازی‌های فعلی
- مار کلاسیک — کیبورد، لمس و جهت‌های دسته
- 2048 — کیبورد، لمس و جهت‌های دسته
- دوز — دو نفره محلی و قابل کنترل با دسته
- حافظه تصویری — لمس، کیبورد و دسته

## انتشار با GitHub Pages
1. در تنظیمات مخزن، بخش **Settings → Pages** را باز کن.
2. در **Build and deployment** گزینه **Deploy from a branch** را انتخاب کن.
3. شاخه اصلی (معمولاً `main`) و پوشه `/(root)` را انتخاب و Save کن.
4. چند دقیقه صبر کن تا سایت منتشر شود.

## حالت کنسول
دکمه «حالت کنسول» را بالای صفحه فعال کن. برای شناسایی دسته، یک دکمه روی آن فشار بده. از D-pad یا آنالوگ برای جابه‌جایی و دکمه اصلی برای انتخاب استفاده کن. پشتیبانی واقعی به مرورگر و دستگاه بستگی دارد و باید روی کنسول موردنظر آزمایش شود. بازی‌های این نسخه داخل همین سایت اجرا می‌شوند؛ بنابراین به iframe خارجی وابسته نیستند.

## منابع بررسی
این پروژه‌ها برای بررسی ساختار و ایده‌های بازی‌های مرورگری استفاده شده‌اند؛ کد بازی‌های این نسخه مستقل نوشته شده و از آن مخزن‌ها کپی نشده است.
- https://github.com/mashukui/web-games — مجموعه بازی‌های تک‌فایلی HTML5 با مجوز MIT طبق README مخزن
- https://github.com/emjay045/browser-games — نمونه بازی‌های مرورگری مستقل
- https://opensourcegames.dev/ — فهرست و کشف بازی‌های متن‌باز
- https://developer.mozilla.org/en-US/docs/Web/API/Gamepad_API — مستندات Gamepad API

## فناوری
HTML, CSS, JavaScript خالص؛ بدون build step و بدون وابستگی CDN.


## آرشیو رترو
- صفحه `retro.html` شامل ۶۰ عنوان مرجع برای آتاری ۲۶۰۰، پلی‌استیشن ۱ و پلی‌استیشن ۲ است.
- آتاری و PS1 امکان انتخاب فایل بازی شخصی از دستگاه و تلاش برای اجرا با EmulatorJS را دارند؛ به اینترنت برای بارگذاری هسته شبیه‌ساز نیاز است.
- فایل ROM و BIOS بازی‌های تجاری در مخزن میزبانی نمی‌شوند. فقط از فایل‌هایی استفاده کنید که مجاز به استفاده از آن‌ها هستید.
- فهرست PS2 فعلاً اطلاعاتی است، چون EmulatorJS در مستندات فعلی خود پشتیبانی PS2 را فهرست نکرده است.
- منابع فنی: https://github.com/EmulatorJS/EmulatorJS ، https://github.com/mohrt/atari2600 ، https://emulatorjs.org/docs/systems/

## کتابخانهٔ گسترده بازی‌ها
صفحهٔ `library.html` یک فهرست جست‌وجوپذیر از مجموعه‌های بازی مرورگری، بازی‌های متن‌باز، پروژه‌های سه‌بعدی و ابزارهای رترو دارد:
- [کتابخانهٔ بازی‌ها](https://sahandse.github.io/games/library.html)
- [آرشیو رترو](https://sahandse.github.io/games/retro.html)
- [صفحهٔ اصلی](https://sahandse.github.io/games/)

این کتابخانه لینک نسخهٔ رسمیِ قابل بازی و مخزن پروژه را جداگانه نشان می‌دهد. به‌دلیل تفاوت مجوزها و محدودیت‌های iframe، سایت‌ها یا کدهای بیرونی به‌طور خودکار داخل مخزن کپی یا درون صفحه جاسازی نشده‌اند. بعضی پروژه‌ها نیازمند سرور، فایل‌های بازی اصلی، BIOS/ROM مجاز یا مراحل ساخت هستند. تعداد و دسترسی لینک‌ها در طول زمان ممکن است تغییر کند.

## TypeScript و Build
منطق سه صفحه در فایل‌های `src/main.ts`, `src/library.ts` و `src/retro.ts` نگهداری می‌شود. Vite آن‌ها را برای انتشار به JavaScript بهینه‌شده تبدیل می‌کند.
- `npm install` نصب وابستگی‌ها
- `npm run typecheck` بررسی TypeScript
- `npm run build` بررسی نوع‌ها و ساخت خروجی چندصفحه‌ای در `dist/`
- `npm run dev` اجرای محیط توسعه
فرایند GitHub Actions قبل از انتشار، build را اجرا می‌کند و فقط پوشهٔ `dist` را به GitHub Pages می‌فرستد.
